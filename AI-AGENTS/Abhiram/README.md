# Abhiram - AI Agent UI Templates

This folder contains the four UI templates assigned to Abhiram.

## Templates
1. Agent Error & Retry
2. Multi-Agent Workflow
3. Automation Workflow Builder
4. Trigger & Action Workflow

## Technologies
- HTML
- CSS
- JavaScript

## Research
### Agent Error & Retry
This UI pattern is used to show failed agent tasks and provide a retry action. It is useful in systems where automated tasks can fail because of connection, input, or server problems.

### Multi-Agent Workflow
This pattern represents several agents working together on one task. It helps users understand the order and status of work performed by different agents.

### Automation Workflow Builder
This interface is used to create an automation by selecting a trigger, condition, and action. It makes workflow creation easier to understand visually.

### Trigger & Action Workflow
This pattern manages existing automation rules. Users can see what starts an automation and what action is performed.

The templates use simple JavaScript interactions such as retry status changes, workflow simulation, live workflow preview, search, filters, and enable/disable controls.
